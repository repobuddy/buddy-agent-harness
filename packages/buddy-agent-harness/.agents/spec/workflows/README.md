# Workflows

> Descriptive index — flows that cross the skill and CLI surfaces.

A flow belongs here when no single surface owns it: one surface produces something a second consumes, and the contract between them is what makes the pair work. A flow written inside one of its two participants reads as that participant's private detail, and the other side is then free to drift from it.
