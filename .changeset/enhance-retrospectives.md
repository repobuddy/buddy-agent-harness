`enhance` offers a new Retrospectives addition for `AGENTS.md`. It tells the agent, when it finishes a task for the user, to check through the `retro` skill of the [cyber-kaizen](https://github.com/cyber-uni/cyber-kaizen) plugin whether a retrospective is due and do what that skill's setting says; to leave a lesson it notices for a retrospective rather than write it into an instruction file or skill itself; and, where that skill is not available, to say so. Where it is not installed, the offer names cyber-kaizen as the plugin to install with it. An `AGENTS.md` whose only such guidance writes each lesson straight into an instruction file or a learnings file still gets it offered.
