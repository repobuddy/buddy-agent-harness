Documents the `reference` command as `cyber-agentkit` 2.0 defines it: `reference load`, `reference customize --extends`, `--in <folder>` for a folder's project section, `--scope repo|user`, and the merge operations `replace`, `patch`, `combine`, and `remove`. The docs, the spec, and `llms.txt` no longer name `reference show`, `reference select`, `--scope project`, or `merge-sections`, and the library page lists only the reference exports the package has.
