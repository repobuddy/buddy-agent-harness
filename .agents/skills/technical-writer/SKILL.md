# Writing style

- Write one instruction per sentence. Keep sentences shorter than 20 words.
- Use active voice. Use the imperative for procedures.
- Use one term for each concept, as defined in `apps/web/src/content/docs/reference/glossary.md`. Do not change the term for variety.
- Do not use idiom or metaphor.

These rules cover prose you write. Leave code samples, command output, and quoted vendor text unchanged.
