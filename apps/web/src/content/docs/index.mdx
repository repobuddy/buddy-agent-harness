## What it does

Buddy Agent Harness uses the repository root's `AGENTS.md` and `.agents/` tree as canonical agent configuration: `.agents/AGENTS.md` holds shared behavior, `.agents/skills/**/SKILL.md` holds capabilities, and separately named files hold tool settings. It preserves user-authored configuration and projects only compatible artifacts into enabled coding-agent harnesses.

## Install

Install the plugin and its `harness-init` skill with `npx skills`:

```sh
npx skills add repobuddy/buddy-agent-harness --plugin
```

For Claude Code, add the marketplace and install the plugin:

```text
/plugin marketplace add repobuddy/buddy-agent-harness
/plugin install buddy-agent-harness@repobuddy
```

Other agent clients can install the same plugin through their marketplace, or use `npx skills` above.

## Use the skill

Ask your agent to initialize the repository's configuration, or run the CLI directly. The active harness is configured by default; explicit user preferences can add other supported harnesses.

## CLI

After the npm package is published, run the CLI without a global installation:

```sh
npx -y buddy-agent-harness init
```

The default output is token-efficient TOON. Use `--format json` when another program requires JSON, `--copy` when symlinks are unavailable, and `--force` only when replacing existing targets is intended.

Run `buddy-agent-harness init --help` to see all options.
